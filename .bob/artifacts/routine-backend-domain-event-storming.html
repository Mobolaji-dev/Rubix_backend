✅ Task Lifecycle routers/tasks.py · services/task.py
EventTask Created
CommandPOST /tasks
Tablestasks INSERT
Initial statestatus = unallocated
EventTask Time Allocated
CommandPATCH /tasks/{date}/{index}/allocate
Tablestasks UPDATE (allocated_minutes, status→ready)
Side FXInvalidates performance cache
EventTask Timer Started
CommandPATCH /tasks/{date}/{index}/start
Tablestasks UPDATE (started_at, status→running) — partial index enforces one active timer per user
Guard409 if another timer already running
EventTask Timer Extended
CommandPATCH /tasks/{date}/{index}/extend
Tablestasks UPDATE (allocated_minutes +Δ, extension_used→true) — one-time per task
EventTask Confirmed (Completed)
CommandPATCH /tasks/{date}/{index}/confirm
Tablestasks UPDATE (status→completed) · streaks recalculate · rank_points +2pts · feed_entries INSERT
Side FXPush: rank_surpassed / leaderboard_topped if overtaken
TriggersStreak Recalculated · Points Awarded · Feed Event Posted · Leaderboard Checked
EventTask Abandoned
CommandPOST /tasks/{task_id}/abandon
Tablestasks UPDATE (status→abandoned)
Side FXInvalidates performance cache
EventTask Reignited
CommandPATCH /tasks/{date}/{index}/reignite
Tablestasks UPDATE (status→unallocated, clear allocated_minutes/started_at/extension_used)
EventTasks Reordered
CommandPUT /tasks/reorder
Tablestasks UPDATE (task_index) for each id in list
EventTask Auto-Missed
TriggerJob auto_miss (scheduled, distributed lock)
Tablestasks SELECT (unallocated/ready/running) + UPDATE (status→missed) · users SELECT (timezone) · streaks recalculate · feed_entries INSERT
Side FXPush: day_missed notification per affected user
QueryToday's Tasks Fetched

🏆 Leaderboard & Points routers/leaderboard.py · services/leaderboard.py
EventPoints Awarded
TriggerTask Confirmed (+2 pts), Todo Ticked (+2 pts), Day Done (+3 pts)
TablesRPC: award_points_atomic → rank_points UPDATE (total_points, tier)
Side FXIf tier threshold crossed → Feed Event "rank_changed" (User Promoted)
EventRank Surpassed
Triggercheck_and_trigger_leaderboard_events after Task Confirmed or Todo Ticked
Tablesfeed_entries INSERT (rank_surpassed)
Side FXPush: "Rank Surpassed" to user who overtook
EventLeaderboard Topped
Triggercheck_and_trigger_leaderboard_events when user takes #1 spot
Tablesfeed_entries INSERT (leaderboard_topped)
Side FXPush: "Leaderboard Topped" notification
EventWeek Closed (Weekly Reset)
TriggerJob weekly_reset (every Monday 00:00 WAT, distributed lock)
Tablessquads SELECT · tasks SELECT (last week) · streaks SELECT · rank_points SELECT+UPDATE · leaderboard_entries UPSERT
Side FXTop 2 finishers promoted · Last place demoted (squad ≥ 3) · Feed events for promotions/demotions
EventUser Promoted
Triggerrank_system.promote_user — called on Week Closed (top 2) or points threshold crossed
Tablesrank_points UPDATE (tier, division) · feed_entries INSERT (rank_changed / promoted)
EventUser Demoted
Triggerrank_system.demote_user — called on Week Closed (last place in squad ≥ 3)
Tablesrank_points UPDATE (tier, division) · feed_entries INSERT (rank_dropped)
