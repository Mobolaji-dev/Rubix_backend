# `bob_sessions/` — IBM Bob IDE Evidence Directory

> ⚠️ **REQUIRED DELIVERABLE FOR HACKATHON JUDGING**  
> Every participant must upload task session consumption summary screenshots from Bob IDE to this folder. Missing this folder disqualifies the project.

---

## 📸 How to Capture & Name Screenshots

1. In **IBM Bob IDE** chat interface, click **Tasks**.
2. Select a task related to this project (e.g., *Task 1: Domain Event Storming*, *Task 2: Bounded Context Identification*).
3. Click the **Task Header** to display the **Task Session Consumption Summary**.
4. Take a PNG screenshot of the summary window.
5. Name the file clearly following this format:
   ```text
   team_task01_event_storming_summary.png
   team_task02_bounded_contexts_summary.png
   team_task03_coupling_audit_summary.png
   team_task04_candidate_ranking_summary.png
   ```
6. Save all `.png` files directly inside this `bob_sessions/` directory before pushing your final commit!
